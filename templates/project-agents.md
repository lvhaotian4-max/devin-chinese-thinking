# 项目级 AGENTS.md 模板

> 使用方法：把以下内容复制到**某个仓库的根目录**，命名为 `AGENTS.md`。
> 只对该仓库的 Devin 会话生效，不影响其他项目。

```markdown
# AGENTS.md

## 语言

- 始终使用简体中文回复用户。
- 所有内部推理/思考链（thinking/reasoning）必须全程使用简体中文；不要生成英文思考链；此要求适用于子代理、计划模式和工具调用前的推理。
- 代码、命令、文件路径、API 名称等技术标识符保持原文，不要翻译。

## 项目约定

<!-- 在这里补充本仓库的构建命令、代码风格、测试方式等 -->
```

## 全局 vs 项目级：怎么选

| 需求 | 推荐方案 |
|---|---|
| 所有项目都想要中文思考链 | 写入全局规则文件 |
| 只有某个开源项目要求中文注释 | 项目级 `AGENTS.md` |
| 团队协作，希望规则进版本库 | 项目级 `AGENTS.md` 并提交到仓库 |

两者可以共存：全局管"语言"，项目级管"项目约定"，互不冲突。
