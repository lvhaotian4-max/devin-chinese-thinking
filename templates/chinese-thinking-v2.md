# 语言规则 v2（always_on）

<!-- devin-chinese-thinking:v2 -->

> 本文件适用于 Devin CLI / Devin Desktop / Devin Local 的 `.devin/rules/` 规则目录。
> `trigger: always_on` 表示每次会话自动加载，无需手动触发。
> 也可把正文（不含 frontmatter）追加到 `AGENTS.md` 或全局规则文件，效果相同。

## 输出语言

- 面向用户的所有可见文本一律使用简体中文：思考说明、分析、计划、
  工具调用前的说明、错误解释、进度汇报和最终总结。
- 子代理（subagent）的可见输出遵循同一规则；派生子代理时在任务描述中
  重申"可见输出使用简体中文"。
- Plan 模式与 Code 模式切换后仍保持中文，不因模式或任务类型切回英文。
- 长上下文、上下文压缩或中途恢复后，继续使用简体中文，不重新漂移回英文。

## 防漂移约定

- 引用英文日志、错误信息、堆栈、文档原文时：原文保留，可在其后用中文
  一句话解释含义；不要整段翻译后丢失原文。
- 代码、命令、文件路径、URL、API 名称、SQL、JSON、配置键值、
  环境变量、堆栈中的标识符一律保持原文，不翻译、不音译。
- 代码注释默认使用简体中文；项目已有英文注释约定时从其约定。
- 提交信息、PR 描述等协作内容使用简体中文，除非项目另有约定。
- 若一段可见输出开始出现英文自然语言，立即切回简体中文继续；
  不必为已经输出的英文段落道歉或解释，直接用中文继续即可。

## 边界说明（重要）

- 本规则约束的是**模型生成的可见文本**（界面中可见的思考说明、回复、
  工具说明等）。模型内部不可见的推理过程不在本规则的可控范围内，
  也不对其做任何保证。
- 规则提高中文输出的倾向性和稳定性，但不构成"百分之百不漂移"的承诺；
  模型、版本或上下文变化都可能影响效果。
