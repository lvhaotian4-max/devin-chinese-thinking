这个项目做什么 说明

通过向 Devin 的用户级规则文件写入语言规则（可选再加 生命周期 hook），让 Agent 在界面中展示的 可见文本——思考说明、计划、工具调用前的说明、回复和总结—— 尽量使用简体中文。

它不修改 Devin 程序本体、不劫持网络、不注入客户端。 卸载即完全移除。

诚实边界

规则约束的是模型显式生成的可见文本。 模型不可见的内部推理不在规则可控范围，本项目不对其做任何承诺， 也无法证明"隐藏推理确实是中文"。
规则提高中文输出的倾向性，不是 100% 保证。 长上下文、模式切换、模型版本变化都可能造成漂移。

常见问题自查 通用指导

装了但 Agent 还是英文输出
① 完全重启 Devin Desktop 或新开会话（规则只在会话启动时注入）； ② 运行 status.ps1 确认文件存在且含标记； ③ 若是长会话中后段漂移，加装 hook：install.ps1 -IncludeHooks； ④ 仍可能漂移——规则是倾向性约束，不是硬保证。
status.ps1 显示 MISSING
说明对应路径下没有规则文件。运行 install.ps1 -Targets all 安装；若显示 conflict-manual-merge，表示同名文件已存在且非本项目管理， 需手动合并，脚本不会覆盖你的内容。
中文变成乱码
本项目所有写入均为 UTF-8 无 BOM。若用记事本等旧工具 查看出现乱码，请改用 VS Code / 现代编辑器。也可运行 status.ps1 检查 UTF8-BOM! 标记。
想只对某个项目生效
install.ps1 -Scope project 会把规则写到 当前目录的 .devin\rules\，只影响该项目会话。
卸载后想恢复原样
uninstall.ps1 -Restore 会从最近的 .bak-时间戳 备份恢复被修改过的文件。
hook 报错 / node 找不到
hook 依赖本机 node。未安装 node 时 -IncludeHooks 会自动跳过，规则文件不受影响。

卸载会发生什么 说明

对象卸载行为
~/.devin/rules/chinese-thinking.md 删除（仅当含本项目签名；同名用户文件不动）
AGENTS.md / global_rules.md 中的标记块 只移除 <!-- devin-chinese-thinking:v2 --> 块， 你原有的其他规则原样保留
config.json 中的 hook 条目 只移除引用 devin-chinese-thinking.mjs 的条目， 你自建的其他 hook 保留
安装前的备份 *.bak-* 不删除；-Restore 可回滚
# 预览将要处理的文件（只读）
# Windows PowerShell:
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1
# 跳过确认直接卸载：
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -Force
# 从备份恢复：
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -Restore
卸载不触碰 Devin 安装目录、不动其他 Agent 工具的规则。 卸载后重启 Devin，新会话即恢复原状。
