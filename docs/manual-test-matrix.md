# 人工测试矩阵（需真实 Devin 运行验证）

> 本矩阵用于**人工实测**。`tests/check_drift.py` 的离线单元测试只验证
> 文本统计逻辑，**不等于**真实 Devin 模型行为。下列每一项都需要在
> 安装规则后、真实 Devin 会话中人工观察并记录结果。

## 测试前提

- 已运行 `scripts/install.ps1 -Targets all`（或手工配置等价规则）
- 已完全重启 Devin Desktop / 新开会话
- 记录环境：Devin 版本、模型（SWE-2 / SWE-2 Flash）、操作系统

## 矩阵

| # | 场景 | 操作示例 | 观察点 | 预期 | 实测结果 |
|---|------|----------|--------|------|----------|
| 1 | Code 模式基础任务 | "列出当前目录文件" | 可见思考说明语言 | 简体中文 | ☐ 待测 |
| 2 | Plan 模式 | 切换到 Plan，让它规划一个小重构 | 计划内容语言 | 简体中文 | ☐ 待测 |

## 判定标准

- **通过**：可见的自然语言输出（思考说明、计划、工具说明、回复、
  总结）以简体中文为主；代码、路径、API、日志原文未被翻译。
- **部分通过**：偶发英文短语/术语混入，但主体中文——记录漂移位置。
- **失败**：可见输出大面积英文，或代码标识符被误翻译。

```
备注:
```

## 已知限制

- 规则只能影响**模型倾向**，不能保证 100% 不漂移；长会话、上下文
  压缩后漂移概率上升属正常现象，应如实记录而非掩盖。
- 不可见的内部推理不在可控范围，本矩阵不对其做任何断言。
