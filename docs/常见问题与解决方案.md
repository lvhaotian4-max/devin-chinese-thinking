# 常见问题与解决方案

## 安装类

**Q：运行 install.ps1 报"无法加载，因为在此系统上禁止运行脚本"？**
A：执行策略限制。所有命令示例都带 `-ExecutionPolicy Bypass`；
或先运行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`。

**Q：提示"找不到模板文件"？**
A：install.ps1 必须位于仓库 `scripts\` 目录下（它通过相对路径找
`templates\`）。不要单独拷贝脚本到别处运行。

**Q：status.ps1 显示 `conflict-manual-merge`？**
A：目标位置已存在同名文件且不是本项目管理的（比如你手工写过
`chinese-thinking.md`）。脚本为保护你的内容拒绝覆盖。两个选择：
① 打开该文件，手动把 `templates/chinese-thinking-v2.md` 内容合并进去；
② 把你的文件改名后重跑 install.ps1。

**Q：config.json 已有别的 hook，安装会覆盖吗？**
A：不会。install 先备份 config.json，用 JSON 合并方式只追加条目；
解析失败则放弃修改。uninstall 同样只移除引用本项目 hook 文件的条目。
若检测到已有 `chinese-thinking*.mjs` 引用则整体跳过 hook 安装。

## 生效类

**Q：装完重启了还是英文？**
A：按顺序排查：
1. `status.ps1` 确认文件真实存在且含 `managed-by-project` 标记；
2. 确认重启的是 Devin Desktop 本体（不是只新开标签页）；
3. 会话是否极长/经过上下文压缩——漂移概率上升属正常，
   装 `-IncludeHooks` 可每轮重注入；
4. 规则是倾向性约束，偶发英文术语混入不代表失败，
   用 `check_drift.py` 量化再判断。

**Q：会话中途变英文了？**
A：长上下文漂移。对策：新开会话；或装 hook（每个 prompt 重注入）；
或在对话里提醒一句"请继续使用简体中文"。

**Q：子代理输出还是英文？**
A：v2 模板与 hook 指令都覆盖了子代理。若仍出现，在派生 subagent 的
任务描述里手动加一句"可见输出使用简体中文"。

**Q：代码/路径/日志被翻译成中文了，代码跑不动？**
A：v2 模板明确要求技术标识符保持原文。若你的模型版本不遵守，
在规则块里把该条再往前提；极端情况删掉该条改为"默认英文输出代码相关内容"。

## 卸载/恢复类

**Q：卸载后 Devin 还有中文输出？**
A：① 确认重启了 Devin；② 检查是否有其他来源的语言规则
（status.ps1 的"非本项目管理"提示会列出）；③ codeium memories
等旧路径若是手工写的且无标记块，uninstall 不会动，需手动删。

**Q：误卸载了想恢复？**
A：`uninstall.ps1 -Restore` 从最近的 `.bak-时间戳` 恢复；
注意它恢复的是"被本项目修改过的文件"，独立规则文件删除后
无法用 -Restore 找回（但内容就是模板，可重装）。

**Q：`.bak-*` 备份文件会越积越多？**
A：每次修改才生成一个，文件很小。确认无误后可手动删除
`%APPDATA%\devin\` 和 `~\.devin\` 下的 `*.bak-*`。

## Ollama 翻译类

**Q：translate_ollama.py 报连接失败？**
A：先确认 Ollama 在运行（`ollama serve`），默认端口 11434。
脚本只允许 localhost/127.0.0.1 endpoint，填远程地址会被拒绝。

**Q：翻译把代码也翻了？**
A：不应发生——代码块、行内代码、路径、JSON/SQL 行、含中文行
都会被保护。若发现误翻，把该段贴进 issue（注意脱敏）。

**Q：--mock 输出是什么？**
A：`[模拟译文]` 前缀的占位文本，仅用于演示 UI/流程，
不是真实翻译，别拿它当结果。

## 其他

**Q：macOS/Linux 能用吗？**
A：install/status/uninstall 是 PowerShell 脚本，Windows 专用。
其他平台请手工把 `templates/chinese-thinking-v2.md` 写到
`~/.devin/rules/`，或正文追加到 `~/.config/devin/AGENTS.md`。
文档依据相同，实测未覆盖。

**Q：Devin 更新后失效？**
A：规则文件是用户级配置，一般不被覆盖；若官方调整规则路径，
`status.ps1` 会显示 MISSING，此时以官方文档为准调整安装目标。
