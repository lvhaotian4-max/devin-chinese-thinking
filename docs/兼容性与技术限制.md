# 兼容性与技术限制

## 已确认的机制边界

| 能做 | 不能做 |
|---|---|
| 向规则文件/hook 写入语言指令 | 修改 Devin 程序本体或其安装目录 |
| 让模型**倾向于**用中文生成可见文本 | 保证 100% 不漂移 |
| 约束可见的思考说明、计划、工具说明、回复 | 控制不可见的内部推理（hidden reasoning） |
| 对用户复制出的文本做本地翻译对照 | 自动抓取 Devin 界面文本做实时翻译 |
| 备份/幂等/安全卸载用户目录下的配置 | 读取或修改其他 Agent（Cursor 等）的私有配置 |

## 平台兼容性

| 平台 | 规则路径 | 脚本支持 | 验证状态 |
|---|---|---|---|
| Windows + Devin Desktop | `%APPDATA%\devin\AGENTS.md`、`~\.devin\rules\`、codeium memories、`config.json` hooks | ✅ install/status/uninstall/test.ps1 | ✅ 本机实测 |
| Windows + Devin CLI | 同上 | ✅ 脚本可写入 | ⚠️ 本机无 CLI，未实测 |
| macOS / Linux | `~/.config/devin/AGENTS.md`、`~/.devin/rules/` | ❌ ps1 不通用，需手工 | ⚠️ 文档依据，未实测 |
| 其他 Windsurf 系 Agent | `.windsurf/rules/`、codeium memories | 部分（legacy 路径） | ⚠️ 理论兼容 |

## 模型兼容性

- 规则/hook 是**模型无关**的上下文指令：任何接受系统提示的模型都
  "能看到"它，但遵循程度取决于模型本身；
- 已实测：SWE-2（本会话）；SWE-2 Flash 作者早期截图；
- 未实测：其他模型、云端 Devin 会话（hooks 文档称云会话经插件
  也支持同样事件，但本项目未验证）。

## 技术限制（诚实清单）

1. **倾向性而非保证**：规则提高中文输出概率，不构成硬约束。
   证据：模型在长上下文、模式切换后仍可能漂移——这正是 hook
   方案存在的理由。
2. **不可见推理不可控**：hidden reasoning 是否为中文无法观测、
   无法证明。本项目所有表述都只针对可见文本。
3. **加载时机**：规则文件在会话启动时注入；hook 在每次提问注入。
   已打开的会话不会热更新。
4. **路径变动风险**：官方若调整规则目录或 hooks 配置格式，
   旧路径可能失效；`status.ps1` 可检测 MISSING。
5. **多机制叠加无法精确归因**：本机同时存在规则文件 + hook，
   中文效果是三者叠加结果，无法说"就是 hook 的功劳"；
   但机制上 hook 的每轮重注入最能解释长会话稳定性。
6. **Ollama 翻译的边界**：仅用户主动提供的文本；localhost 限定；
   质量依赖所选模型；无原生实时集成。
7. **check_drift.py 的边界**：统计的是用户提供的可见文本样本，
   样本量和代表性由用户决定，不能外推为整体漂移率。
