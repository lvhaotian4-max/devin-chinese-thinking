# 完整运行流程

从克隆仓库到确认中文生效的全步骤指南（Windows）。

## 0. 前置条件

- Windows 10/11，已安装 Devin Desktop（本项目在 1.141.2 上验证）
- PowerShell（Windows 自带 5.1 即可）
- 可选：node（仅 `-IncludeHooks` 需要）、Python 3.8+（仅 check_drift /
  translate_ollama 需要）、本机 Ollama（仅翻译原型需要）

## 1. 获取仓库

```powershell
git clone https://github.com/lvhaotian4-max/devin-chinese-thinking
cd devin-chinese-thinking
```

## 2. 安装规则（按需选择）

```powershell
# 基础安装：新版 + 旧版兼容路径都写入
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Targets all

# 推荐：同时安装 hook（每次提问重新注入，抗漂移最强；需 node）
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Targets all -IncludeHooks

# 只对当前项目生效
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Scope project

# 预览将要做什么（不写文件）
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Targets all -WhatIfOnly
```

安装会做的事：探测候选路径 → 备份已有文件 → 写入规则（独立规则文件
或向 AGENTS.md/global_rules.md 追加标记块）→（可选）安装 hook 并
合并 config.json。已有非本项目管理的同名文件**不会被覆盖**，只报告冲突。

## 3. 验证安装状态

```powershell
powershell -ExecutionPolicy Bypass -File scripts\status.ps1
```

检查：Devin Desktop 是否安装、node 是否可用、各规则文件是否存在/
含标记/编码/frontmatter、hook 是否注册。全部只读，不改任何文件。

## 4. 重启并观察生效

1. **完全退出并重启 Devin Desktop**（或至少新开一个会话）；
2. 给 Agent 一个任务，例如：`列出当前目录文件`；
3. 观察可见的思考说明、计划、工具调用前的说明——应以简体中文为主；
4. 子代理场景：`全面搜索 xxx 的用法并总结`（会派生 subagent）；
5. 长会话场景：贴入大段英文文档后继续提问，观察是否漂移回英文。

## 5. 漂移了怎么办

- 短期：新开会话（规则重新注入）；
- 中期：安装 hook `install.ps1 -IncludeHooks`（每次提问重注入）；
- 量化：把界面复制出的可见文本存为 .txt，运行

  ```bash
  python tests\check_drift.py visible.txt
  ```

  得到 drift_ratio（英文段占比），>0.3 视为漂移明显。

## 6. 可选：Ollama 翻译对照

```bash
python scripts\translate_ollama.py visible.txt --mock   # 离线演示
python scripts\translate_ollama.py visible.txt          # 本机 Ollama
```

## 7. 卸载

```powershell
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1          # 预览+确认
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -Force    # 直接卸载
powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1 -Restore  # 从备份回滚
```

卸载只移除本项目管理的标记块/hook 条目/规则文件，你自己的其他规则
和 hook 原样保留。卸载后重启 Devin。

## 8. 流程图

```
clone → install.ps1 → status.ps1 → 重启 Devin → 观察中文输出
                │                        │
                │                        ├─ 漂移 → check_drift.py 量化
                │                        ├─ 持续漂移 → -IncludeHooks 重装
                │                        └─ 需要对照 → translate_ollama.py
                └─ 不想要了 → uninstall.ps1 (-Restore 可回滚)
```
